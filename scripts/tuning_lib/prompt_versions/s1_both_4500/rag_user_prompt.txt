## Task
Step 1. Read each passage and write one short note about it: which feature or part of the product it is about, and whether it fits this user story: "yes", "partly" or "no".

Step 2. Write the security requirements that this user story needs.
- Use only the passages with "yes" or "partly". From a passage with "partly", use only the part that is about this user story.
- State only what a passage says, and only about the names that it describes.
- When a requirement uses a passage that you marked "yes" or "partly", write in its rationale what that passage says about the product, as a fact, with the number of the passage, for example: "The documentation states that ... (passage 3)." Use the names and the values of the passage. Do not write this for something that comes from the user story or from your memory.
- Where no passage fits a point, write the requirement in general words. That is a correct answer.

Write as many requirements as the story needs, and not more.
